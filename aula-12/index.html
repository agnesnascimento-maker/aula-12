BOX MODEL

content (conteudo)

define a largura da caixa (salvo elementos de blobo)

Padding (preenchimento)

Separa o conteúdo das bordas da caixa. é a margem interna

Border (borda)

define a distância ente uma caixa e outra.

width (largura)

A largura total caixa, por padrão é o somatório do conteudo + padding (left/right) + border (left/right)

Height (Altura)

A altura total da caixa, por padrão é o somatório do conteúdo + padding (top/bottom) + border (top/bottom)
